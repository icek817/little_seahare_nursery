Little Hare Nursery
A tiny terminal nursery for simulated sea hares, built with Bash.
MAKE THE HARES EXIST.
Everything else is an optional dependency.

Project status
v0.1 is under development. The commands below describe the planned interface; they are not a claim that the implementation is complete.
This is a personal shell scripting project: create little sea hares, give them names, save their records, and visit them again later.
